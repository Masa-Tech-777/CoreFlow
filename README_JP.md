# CoreFlow

**CPUの動作周波数とターボブーストを、シンプルな操作で管理。**

CoreFlowは、Intel CPUおよびAMD Ryzen CPUに対応した、Windows 11向けの無料CPU電源管理ユーティリティです。

Windows標準の電源管理機能を利用して、CPUの最大周波数、最小性能状態、ターボブーストの動作方針を調整できます。

電源接続時（AC）とバッテリー駆動時（DC）で、それぞれ異なる設定が可能です。

性能を重視したいとき、発熱を抑えたいとき、消費電力とのバランスを調整したいときなど、利用環境に合わせた設定を行えます。

**CoreFlowは完全無料です。ライセンスキーの登録や使用時間の制限はありません。**

---

## 1. 主な機能

- **CPU最大周波数の設定**  
  CPUの最大動作周波数に上限を設定できます。

- **CPU最小性能状態の設定**  
  MHzで入力した値をWindowsの最小プロセッサ性能（%）に換算して適用します。

- **ターボブーストの動作設定**  
  ブーストの無効化や、性能・効率を考慮した動作モードを選択できます。

- **AC・DC別の設定**  
  電源接続時とバッテリー駆動時で、それぞれ異なる値を設定できます。

- **Windows電源プランの選択**  
  設定対象となる電源プランを選び、設定を適用できます。

- **CPUの自動判定**  
  CPU型番を取得し、内蔵のCPU仕様データベースと照合します。

- **変更前の設定への復元**  
  CoreFlowによる変更前の設定へ戻す機能を備えています。

- **アップデート確認・診断ログ保存**  
  アプリ内のヘルプメニューから利用できます。

## 2. 対応環境

| 項目 | 対応内容 |
|---|---|
| OS | Windows 11 64bit |
| CPU | Intel CPU / AMD Ryzen CPU |
| 実行権限 | 管理者権限が必要 |
| 利用料金 | 無料 |
| ライセンス登録 | 不要 |

Windows 10で動作する可能性はありますが、正式サポート対象はWindows 11です。

CPU、BIOS、Windowsの電源管理方式、PCメーカー独自の制御機能などにより、設定の反映状況や動作結果が異なる場合があります。

## 3. 基本的な使い方

1. CoreFlowを起動し、必要な管理者権限を承認します。
2. 設定対象となるWindows電源プランを選択します。
3. AC（電源接続時）とDC（バッテリー駆動時）の設定値を入力します。
4. 必要に応じてブーストモードを選択します。
5. **［設定を適用］** をクリックします。

設定は選択した電源プランへ適用され、その電源プランに切り替わります。

設定後のCPU動作は、WindowsとCPUが自動的に管理します。

## 4. 最大周波数について

最大周波数は100 MHz刻みで設定します。

**0 MHzを指定した場合は、最大周波数の制限なし**として扱います。

CPU型番が内蔵データベースと完全一致した場合、登録されたCPU仕様最大値を参照して入力範囲を決定します。

手入力の上限は、照合できたCPUの仕様最大値から1200 MHzを差し引いた値を基準とします。

CPU型番をデータベースで確認できない場合、最大周波数を推測して設定することはありません。照合できない場合は、最大周波数を0 MHzにしてください。

なお、最大周波数を設定しても、CPUが指定値で常時動作するわけではありません。

CPUの負荷、温度、電源状態などに応じて実際の周波数は変動します。

**CoreFlowはCPUをオーバークロックするツールではありません。**

## 5. 最小周波数について

最小周波数は、画面に表示される下限値から選択します。基本となる下限値は1400 MHzです。

入力したMHz値は、Windowsの「最小のプロセッサの状態（%）」に換算して適用されます。

そのため、指定した周波数でCPUを固定する機能ではありません。

実際のCPUクロックは、負荷やWindows・CPUの電源管理に応じて変動します。

## 6. ターボブーストについて

CoreFlowでは、Windowsの「Processor Performance Boost Mode」を利用して、CPUのブースト動作方針を設定できます。

Astra時代の仕様資料では、次の7種類（設定値0～6）が説明されています。

| 値 | モード |
|---|---|
| 0 | 無効（Disabled） |
| 1 | 有効（Enabled） |
| 2 | アグレッシブ（Aggressive） |
| 3 | 効率的な有効化（Efficient Enabled） |
| 4 | 効率的なアグレッシブ（Efficient Aggressive） |
| 5 | アグレッシブ（保証性能基準） |
| 6 | 効率的なアグレッシブ（保証性能基準） |

各モードは、WindowsとCPUに対してブースト動作の方針を指定するものです。

CPUの周波数を固定したり、必ず高い周波数や低い温度を実現したりする機能ではありません。

同じモードでも、CPUやファームウェア、Windowsの性能制御方式によって動作結果は異なります。

最大周波数の上限を設定している場合でも、その範囲内でブーストが動作する場合があります。

## 7. CPU仕様データベース

CoreFlowには、CPUの仕様を参照するためのデータベースが内蔵されています。

CPU型番の照合には完全一致方式を採用しています。

型番を確認できないCPUについて、基本周波数や最大周波数を推測して利用することはありません。

CPU仕様の照合そのものにインターネット接続は不要です。

## 8. 設定を元に戻す

CoreFlowで変更したCPU電源設定を元に戻したい場合は、**［変更前へ復元］** を使用してください。

アプリを削除する前にも、必要に応じて復元を行ってください。

Windowsの電源設定は、CoreFlowの実行ファイルを削除しただけでは元に戻らない場合があります。

## 11. アンインストール

専用アンインストーラーはありません。

削除する際は、次の手順を参考にしてください。

1. 必要に応じて［変更前へ復元］を実行します。
2. CoreFlowを終了します。
3. CoreFlowの実行ファイルを削除します。

Windows側へ適用済みの設定が残る可能性があるため、削除前の復元を推奨します。

## 12. ご利用上の注意

CoreFlowはWindows標準の電源管理機能を利用するユーティリティです。

独自のカーネルドライバによる制御や、CPU電圧・BIOS設定の直接変更は行いません。

ただし、CPUの電源設定を変更する性質上、環境や設定値によっては動作速度の低下、予期しない挙動、一時的なフリーズなどが発生する可能性があります。

また、実際のCPU動作は次のような要因に影響されます。

- CPUの仕様と電源管理方式
- Windowsのバージョンと電源プラン
- CPUの負荷と温度
- BIOS・ファームウェア
- PCメーカー独自の電源管理機能

設定した周波数と実際の動作周波数が常に一致することを保証するものではありません。

利用者ご自身の環境に合わせて、無理のない設定でご使用ください。
