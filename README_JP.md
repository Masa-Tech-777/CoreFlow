## CoreFlow 無料版の周波数設定について

CoreFlowは無料で利用できるCPU電源管理ユーティリティです。

無料版では、CPUの動作周波数に対して次の設定制限を設けています。

### 最大周波数の設定制限

CPU型番を自動判定し、内蔵のCPU仕様データベースと完全一致した場合に限り、メーカー仕様の最大周波数を参照します。

**最大周波数の手入力上限は、CPUの仕様最大周波数から1200 MHzを差し引いた値を基準とします。**

例えば、仕様最大周波数が5000 MHzのCPUであれば、手入力上限の基準は3800 MHzです。

- 周波数は100 MHz刻みで設定できます。
- 最大周波数の「0 MHz」は制限なしを意味します。
- CPU型番がデータベースと一致しない場合は、最大周波数を推測しません。その場合は0 MHzを使用してください。
- この設定はCPUのオーバークロックを行うものではありません。

### 最小周波数の設定制限

最小周波数の入力下限は、基本的に1400 MHzです。

実際の設定可能範囲は、アプリ画面に表示される値に従ってください。

なお、最小周波数の入力値はWindowsの「最小のプロセッサの状態（%）」へ換算されるため、指定したMHzでCPUのクロックが固定されるわけではありません。

### 周波数制限についての注意

これらはCoreFlow無料版の設定範囲に関する制限です。

実際のCPU周波数は、CPUの仕様、Windowsの電源管理、負荷、温度、BIOSなどの影響によって変動します。
